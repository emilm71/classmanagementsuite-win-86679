## About Class Management Tools

Class Management Tools brings a collection of teacher-focused utilities into one workspace. It supports class and student group organization, classroom sessions, scoring, grade records, lesson preparation, assessments, and participation review.

The suite is designed for educators who need practical tools across planning and teaching activities. It also includes vocabulary and grammar learning games, oral exam workflows, seating plan design, data import, shared synchronization between tools, and export options for common document and data formats.

## Features

- Manage classes, student groups, and individual student records.
- Run classroom sessions with timers, scoring, and participation analytics.
- Track grades, tests, and assessment results.
- Plan lessons and organize upcoming assessments.
- Use vocabulary and grammar learning games for language activities.
- Schedule oral exams and record marks during live sessions.
- Create and adjust classroom seating plans.
- Import student and class data, then synchronize it across supported tools.
- Edit documents with Markdown and LaTeX support.
- Export information to PDF, CSV, XLSX, JSON, ICS, and HTML.

## Usage

A typical workflow can be organized as follows:

1. Create a class or import existing class and student data.
2. Arrange students into groups and design a seating plan.
3. Prepare a lesson or assessment plan.
4. Start a classroom session with the timer and scoring tools.
5. Record participation, grades, test results, or oral exam marks.
6. Review class-level information through the available analytics.
7. Export records or documents in the format needed for further use.

For language-focused activities, open the vocabulary or grammar games, select the relevant learning material, and use the activity during a lesson or review session.
